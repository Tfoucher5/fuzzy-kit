Extensions ​

Language packs teach fuzzy-toolkit how a language writes numbers, its articles, stop words and how it sounds. Presets are ready-made settings for one kind of data: song titles, addresses, company names... See Languages and presets to use or write one.

Shipped with fuzzy-toolkit

enlanguageBuilt in

English: numbers in words, ordinals, articles, stop words, sounds-alike rules. On by default.

compare(a, b, { languages: ['en'] })
frlanguageBuilt in

French: quatre-vingt-dix, ordinals, articles and elisions (l'), stop words, sounds-alike rules. On by default.

compare(a, b, { languages: ['fr'] })
eslanguageBuilt in

Spanish: treinta y dos, veintiuno, ordinals, articles, stop words, sounds-alike rules (b/v, ll/y, silent h).

import es from 'fuzzy-toolkit/lang/es'
compare(a, b, { languages: [es] })
delanguageBuilt in

German: einundzwanzig, ordinals, articles, stop words, sounds-alike rules (Müller = Mueller, Meier = Mayer).

import de from 'fuzzy-toolkit/lang/de'
compare(a, b, { languages: [de] })
itlanguageBuilt in

Italian: ventitré, ventuno, ordinals, articles and elisions, stop words, sounds-alike rules.

import it from 'fuzzy-toolkit/lang/it'
compare(a, b, { languages: [it] })
nllanguageBuilt in

Dutch: eenentwintig, een en twintig, ordinals, articles, stop words, sounds-alike rules (ij/ei, v/f, z/s).

import nl from 'fuzzy-toolkit/lang/nl'
compare(a, b, { languages: [nl] })
musicpresetBuilt in

Song titles and artists: drops featurings, "Remastered", brackets and leading articles; & = and.

compare(a, b, { preset: 'music' })
searchpresetBuilt in

Search as you type: prefixes, acronyms, lower threshold.

compare(a, b, { preset: 'search' })
strictpresetBuilt in

Word order and spaces matter, threshold 90.

compare(a, b, { preset: 'strict' })

Add yours ​

  1. Write your pack with defineLanguage() or definePreset() and test it with fuzzy-toolkit/testing.
  2. Publish it on npm as fuzzy-toolkit-lang-<code> or fuzzy-toolkit-preset-<name>, with the keyword fuzzy-toolkit-plugin (details). It shows up here on the next rebuild of the site, at least once a week.
  3. Optional: to get the Reviewed badge, open a pull request that adds it to docs/extensions.json:
json
{
  "package": "fuzzy-toolkit-lang-pt",
  "kind": "language",
  "id": "pt",
  "description": "Portuguese: vinte e um, ordinals, articles, stop words, sounds-alike rules.",
  "repository": "https://github.com/you/fuzzy-toolkit-lang-pt"
}

A maintainer checks that the package does what it says and that its tests use fuzzy-toolkit/testing. A pack good enough for everyone can also be proposed for the core: open a "Language request" or "Preset proposal" issue.
