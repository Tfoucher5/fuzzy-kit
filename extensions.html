Teach it your data.

Language packs teach fuzzy-toolkit how a language writes numbers, its articles, stop words and how it sounds. Presets are ready-made settings for one kind of data: song titles, addresses, company names.

Add yours

From idea to npm in one command.

  1. Start the package. new-pack writes package.json, the pack and a test that uses fuzzy-toolkit/testing.
  2. Publish it as fuzzy-toolkit-lang-<code> or fuzzy-toolkit-preset-<name> with the keyword fuzzy-toolkit-plugin. It shows up on this page at the next rebuild, at least once a week.
  3. Get the Reviewed badge (optional): a pull request that adds it to docs/extensions.json.
Writing a pack, step by step
~/packs
$ npx fuzzy-toolkit new-pack language pt
Created ./fuzzy-toolkit-lang-pt
package.json index.js index.test.js README.md
$ cd fuzzy-toolkit-lang-pt && npm install
$ npm test
✔ pt: vinte e um = 21, o/a/os/as stripped
$ npm publish
+ fuzzy-toolkit-lang-pt@0.1.0 → listed here
Reviewed badge

One entry in a JSON file

A maintainer checks that the package does what it says and that its tests use fuzzy-toolkit/testing. A pack good enough for everyone can also go into the core: open a Language request or Preset proposal. 

{
  "package": "fuzzy-toolkit-lang-pt",
  "kind": "language",
  "id": "pt",
  "description": "Portuguese: vinte e um, ordinals, articles, stop words.",
  "repository": "https://github.com/you/fuzzy-toolkit-lang-pt"
}
